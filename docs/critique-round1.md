# 批評 第1回（2026-10-22）— 名前を伏せた A/B 比較

対戦相手: BoldVoice（結果・練習）、ELSA（音の詳しい説明・ホーム）。批評役は 1 画面ずつ、どちらが自分たちの画面か知らずに判定。

| 画面 | 勝敗 | こちらの点（10点満点: 作り/わかりやすさ/楽しさ/文字/色/持ちやすさ/引き算） |
|---|---|---|
| ホーム | 勝ち | 6 / 7 / 5 / 5 / 5 / 8 / 3 |
| 結果 | 負け（BoldVoice） | 5 / 3 / 7 / 5 / 5 / 8 / 3 |
| 音のカード | 勝ち（ELSA は音ごとの説明が無い） | 6 / 7 / 実行しやすさ 4 / 5 / 5 / 7 / 4 |
| 練習（実際は採点直後の画面） | 負け（BoldVoice） | 4 / 4 / 7 / 4 / 5 / 6 / 4 |

共通の評価: 「見どころ（ステッカーの文字・テンプレでない色・日本語が先）はあるが、試作品の粗が目立ち、感動はしない」。

## 直すこと（優先順）

### 1. 文そのものを診断にする（いちばん効く）
- 単語の下の説明のない点や線をやめる。間違えた文字そのものに色＋形（太字＋波線など）で印をつける。色だけに頼らない（色覚の多様性）。
- 押すとカードが開き、日本語の一行で直し方を言う（例「th が『ザ』に。舌先を前歯に軽く当てて」）。聞こえた音は `src/engine/scoring/heard-labels.ts` の `heardAsJa()` / `insertedVowelJa()` を使う（「R が日本語のラ行の音に聞こえました」）。
- 結果では英文を落ち着いた形（1本の行、1色）にする。ステッカーの派手な文字は、点数か高得点のときだけ。60点で「お祝い」に見えないように。

### 2. カードの中で言い直せる（「わっ」となる瞬間）
- カードに大きな「もう一度言う」（マイク）。その単語だけを録って採点し、その場で結果を更新する。
- 「AIにはこう聞こえた」の目盛りは読み取り専用にして、お手本の位置の印と、両端を押すと right / light を聞ける形に。言い直してうまくいくと、つまみが right 側へ動く。
- 口の図を大きく。「あなた」と「お手本」の舌の位置の違いを重ねて見せる。
- 背景を暗くして、診断の一行をカードの主役にする。×は1つ。最下部のボタンはホームバーの領域（safe-area）に入れない。
- 「r → l」は区別しやすい字で（丸ゴシックの l は I や 1 に見える）。英字には、l に尾がある読みやすい欧文書体を使う（例: Atkinson Hyperlegible Next）。

### 3. 点数の見せ方
- 数字が回っている途中でも読めること（桁ごとに枠で隠して上下に流す、等幅数字、600ms 以内、ばねで止まる）。
- 内訳（音・リズム・抑揚）は整数で、3つを1列に並べて画面の最初に見える所へ。合計は大きく、小数（カラオケらしさ）は小さく控えめに。
- 前回との差（+4 など）を出す。

### 4. 結果の音程グラフ
- 高さを4割ほど減らす。凡例の色と線の色を合わせる（あなた＝黄、お手本＝水色）。
- 声が切れる所は点線でつなぎ、浮いた切れ端や最後の縦の線（不具合に見える）を出さない。
- 一行の読み方を添える（compareProsody の issues から「語尾が下がりすぎ」「平らすぎ」など）。

### 5. ボタンと文言
- 「もう一回」→「もう一度話す」＋マイク。合格したら「次へ」をはっきり主ボタンに（紺の上の紺は押せないように見える）。
- 再生のボタンは高さ 44pt 以上。上の重複したスピーカーのアイコンは消す。
- 進み具合の帯: 今のステップを塗り、先のステップは薄く（今は逆に見える）。

### 6. 引き算
- 黒い縁取り＋影を全部の部品に付けない。主役（点数・カラオケの字幕）だけ。ほかは平らに。
- 色の役割を決める: 誤り＝1色、あなた＝黄、お手本＝水色。電気青の上のコーラルは文字に使わない（ちらつく）。

### 7. ホーム
- 本当の「ルート」に: 済み・今・まだを見分けられる印、番号、今の行を光らせる。
- 数字の体系を1つに: ユニットごとの進みの棒、レッスンごとに星3つの枠。初日に「0/933」を出さない（今日の目標や連続日数に）。
- 文字の太さに階層を: 一番太いのはロゴとユニット名だけ。説明は中くらいの太さ・墨75%、数字は小さく等幅。
- 練習する英単語を大きく、欧文書体で。違う文字（right / light の r と l）を目立たせる。
- 背景を落ち着かせ、色に意味を（黄色の地に琥珀色のカードは消える）。下のボタンの上の硬い線をやめ、フェードに。
- いちばん効く一手: 今やるレッスンを「再生中」のカラオケのカードにする（英単語が大きく、強く読む音節が字幕のように光る、マイク、星3つ）。ほかのユニットは控えめな一覧に。

### 8. 撮影の注意
- 批評用の撮影は本番ビルド（プレビュー URL）で。開発時の「N」バッジが写り込む。
- 「話している最中」は長めの文（3秒以上）で、録音の途中を撮る。
