## 第3版でやること（優先順）

### 1. カラオケの判定を正直に（練習画面の「わっ」）
- **帯の太さ＝当たりの幅**にする（±`pitchTolSt` 半音）。大きさ（w）は太さではなく光の強さで表す。
- 自分の線は `judge.line[i].inBand`（新しく追加。`new KaraokeJudge(syllables, { wave })` で波を渡すと入る）で色分け: 帯の中＝金色に光る、外＝白く細い。点の横に 高い／低い の小さな印。
- GREAT・コンボは、その音節が確定して great 以上のときだけ。同時に2つ出さない（重なりの GREAT が二重に見えた）。音節ごとに軽い触覚（対応する端末だけ）。
- 遅れの許容を 0.3 → 0.2 秒に締めた（エンジン側で済み）。遅れているときは「おそい」の小さな印。
- 見た目の不具合: GREAT の二重表示、文字の塗りが縁取りからはみ出す（半分塗りの I）、帯の左端の白い切れ端、歌い終わった所は薄く消す。
- 字幕の塗りとカーソルを必ず同じ時刻に。単語の名前は、その単語の波の真下に。凡例は線に直接ラベル。カードを下の空きへ広げる。
- 録音中は お手本／自分の声 のボタンを押せない見た目に。波紋がラベルにかからないように。マイクの下の文言は「止める」など、ボタンがすることを書く。

### 2. 文字（4人中2人が「子ども向けに見える」）
- 極太の丸ゴシックは **カラオケの字幕と点数だけ**。ほかの日本語は中くらいの太さのゴシックに。
- 和欧混植を整える: `font-feature-settings: "palt"`、括弧の詰め（3つの「ア」）。音は /r/ → /l/ のような同じ形のチップで（「r がLに」のように大小文字や空白がばらばらにならない）。
- 1画面の文字スタイルは3種類まで。

### 3. 色の意味を2つに
- お手本＝水色、あなた＝黄色。波・線・目盛り・図・再生ボタン・凡例すべてで同じ。誤り＝1色（今の #d6245f）。それ以外の色は使わない。

### 4. 結果を「ひとつの教える瞬間」に
- 結果が出たら、**いちばんまずかった音が自動で開く**（大きな「伝わります」の下に）。口と舌の動きで直し方、お手本／あなたの切り替え。
- 点数の内訳とグラフは「くわしく」の中へたたむ。
- 「65 .300点」の形を直す（合計は「65」と小さく「/100」、小数は残すなら合計の右肩に小さく）。
- 誤りの波線は最低 1.2em の幅で、間違えた文字の中央に（1文字だと✓に見えた）。範囲は「Th」なら Th だけ。
- グラフはなめらかに: お手本の帯の上に自分の線。違う区間だけ薄く塗り、一言の指示（「文末をもっと下げる」）。V 字の突起・浮いた点・点線の切れを出さない。
- 下のボタンは1列に固定、safe-area の外。黄色は「あなた（再生）」だけにして、録音のボタンは別の見た目に。

### 5. 音のカード
- **r↔l の目盛りを主役に**: 端から端までなぞると rice と lice の音がなめらかに切り替わり（2つの音声の重ね合わせで良い）、図の舌も同時に動く。自分の位置はピンで。
- 口の図を描き直す（前歯〜のど手前を大きく切り取った断面図。プロの解剖図の線の質で）。「あなた」は1本の太い黄色の線、お手本は水色。歯ぐきに触れる所に ●／×。
- 直し方は「〜しない」だけでなく、して欲しいことを先に（「舌先を少し奥に引き、どこにも付けずに。唇を軽く丸める」）。「（たぶん）」はやめて「AI の推定」と一度だけ書く。
- 閉じる方法は1つ（つまみ＋下へスワイプ、×は1つ）。カードの下の大きな文字は隠す。お手本の再生ボタンの重複をまとめる。

### 6. ホーム
- 「hotel」の下の「ホテル」（カタカナの読み）をやめる。代わりに強く読む所の形（ho・TEL ／ ・●）。意味は小さく。
- 強い音節は、文字の後ろの丸ではなく、音節ごと太く大きく（ho·**TEL**）。
- **いちばん効く一手**: ホームの大きなカードで「ho·TEL」が、お手本の声に合わせてカラオケの字幕のように左から塗られ、続けて自分の声でも塗られる。
- 数字は場所ごとに1つ、ラベルつき（今日 0/5分 ・ このセット 1/8）。ルートは今のユニットだけ段に開き、先のユニットはたたむか鍵。個数ではなく分で。
- ボタンは「hotel を言ってみる・30秒」のように何が起きるかを書き、親指の届く下に固定。黄色い丸の入れ子をやめる。8pt の間隔のリズム。
