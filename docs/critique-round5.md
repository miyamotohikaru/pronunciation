感動度は 6 で頭打ち。批評役が共通して求める次の一歩は 3 つ。

## 1. 口の図をプロの品質に（音のカードの負けの原因）
- 「唇と歯がカプセル、顔の輪郭がない、舌に見えない、印が10個」。手描きの線では限界。
- **自由に使えるライセンスの、専門家が描いた口の断面図（Wikimedia Commons の public domain / CC BY / CC BY-SA の SVG）を土台にする。** 動かすのは舌だけ（あなた → お手本 の2〜3コマを補間）。ライセンスを確認し、出典をクレジットのページに書く（CC BY-SA なら継承の表記も）。
- 印は3つまで。図の中に凡例。動詞は「指で動かして」。取っ手は 44pt 以上。
- エラーの画面で「いい感じ」をいちばん大きくしない。見出しは診断（「/r/ が /l/ に聞こえました」）。
- 色は3つ（青・誤りのピンク・あなたの琥珀）、文字の大きさは4種類、ラベル 13pt 以上。「あなた」は「あなたの録音」。

## 2. 英文を波に乗せて、見る場所を1か所に（練習）
- **英文そのものを音程の帯の上に置く**（単語が自分の時刻の位置で、メロディーに乗る。強い音節は高く）。録音中は上の大きな字幕を小さくする。
- 言い終えた単語は黄色に。まだの単語は白 90% 以上（いまのピンクは暗すぎる）。単語の間は普通に、つながる所に ‿。
- 帯: 明るい細い芯の線（お手本の音程）＋薄い許容の幅。図の高さの範囲を広げて、帯が全体の 15〜20% の高さに収まるように（いまは半分を占めて、上がり下がりが読めない）。
- 継ぎ目をなくす（区間のパスをつないでから塗る）。端は切らずにフェード。角の丸みで文字が欠けない。自分の線はなめらかに、無声の所は橋渡し。カーソルが説明の札にぶつからない。

## 3. 仕上げ
### 発音記号
- 斜体をやめて立体に。IPA に完全に対応した書体（Noto Sans か Charis SIL、自前で配信）。ɚ の字が欠けて別の書体に置き換わっている。
- 並び順は 英文 → 発音記号 → 和訳。英文の真下に。
- 強勢の印の付け方をそろえる（「強いところはひとつ」のレッスンで、I にも de にも印があって矛盾して見えた）。文の中で弱い機能語の強勢の印は付けないか薄く。

### 結果
- 繰り返しを減らす（The が4回、/ðə/ が3回）。大きな見出しと音のチップの列をやめ、失敗した音から直接開く。
- 文の中の印は、1文字の赤＋細い波線ではなく、音の範囲全体に薄い色の札か 2px の下線。押すとその単語へ。
- はみ出した5つ目のチップと「1/5」の重なり、2種類の数え方（1/5 と進みの帯）をやめる。下の列の下に半分透けたカードを見せない（「くわしく ⌄」に）。
- 下のボタンの形をそろえる（高さ・並び方を1つに）。お手本／あなた の入れ子を浅く。点数に前回との差（+6）。

### ホーム
- 主役のカードの字幕は1つの見た目で（TVの字幕風のもう1つの書体をやめる）。強さは大きさと太さだけ。長い文は自動で縮めて改行の規則を決める。
- 縦の線・点・星を1本の軸に。時間は右端をそろえる。進みの帯は行の幅いっぱい。
- 何も進んでいないときも元気に: 今日の目標の輪は見える下地の上に。「のこり」を何度も書かない。連続日数か、最初の1回のごほうび。
- 今の行に「いまここ」とオレンジの印。カードが画面の外に出たら、マイクのボタンを下に固定。
